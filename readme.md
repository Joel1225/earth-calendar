# Earth Calendar

A website for converting Gregorian dates into the proposed Earth Calendar.

## Files

- index.html: The website.
- README.md: Installation instructions.
- SPECIFICATION.md: Calendar rules.

## Publishing on GitHub Pages

1. Create a GitHub repository named earth-calendar.
2. Upload all three files.
3. Open Settings.
4. Select Pages.
5. Choose Deploy from a branch.
6. Select main and / (root).
7. Save.

Your website will be available at:

https://YOUR-USERNAME.github.io/earth-calendar/
